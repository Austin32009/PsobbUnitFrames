## Installation
Please download `UnitFrames.zip` from **Releases** on the right side of this page.

## Requirements
* [SolyLib](https://github.com/Solybum/PSOBBMod-Addons) is required for this mod to work. 
* Ensure you have the latest version of the PSOBB addon mod (versions older than 3.7.0 are not supported).
